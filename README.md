### <a href="https://github.com/Atulaya123/ai-pr-review-agent">ai-pr-review-agent</a>

A multi-agent AI code reviewer — designed, built, and **deployed live**, end to end.

- 🕸️ **LangGraph** fans a PR diff out to 4 parallel specialist agents (security · quality · tests · docs)
- 🧠 Each agent is grounded via **RAG** over the codebase's own architecture rules — not the diff in isolation
- 🚦 Confidence-weighted **human-in-the-loop gate**, GitHub App auth, LangSmith tracing, full reliability layer
- 🌐 **[Try it live](https://aipr-review-agent.onrender.com/health)** — open a PR against the repo and watch it review in real time
